# Автоответ «ЖАБА» в Инстаграме (ManyChat), решение Кирилла 12.10.2026

Зачем: комментарий под рилсом поднимает охват (так делает конкурент: 784 комментария на 2 876 лайков), а ссылка в директе
с меткой `ct=ig_dm` показывает в App Store Connect, сколько установок пришло из рилсов.

## Что нужно (делает Кирилл, 20–30 минут, вход в аккаунты только руками Кирилла)
1. **Профессиональный аккаунт Инстаграма** (Автор или Бизнес): Настройки → Тип аккаунта и инструменты.
2. **Доступ к сообщениям для сторонних сервисов:** Настройки → Сообщения и ответы на истории → Инструменты для сообщений
   → «Разрешить доступ к сообщениям» — включить.
3. **ManyChat:** manychat.com → Sign up with Instagram → войти в @kubysh.ai. Тариф Free: до 1 000 контактов, этого хватит на октябрь.
4. **Автоматизация:** Automations → шаблон «Auto-DM links from comments»:
   - пост: «Any post or reel» (все рилсы сразу), ключевые слова: `жаба, ЖАБА, Жаба, жабу`;
   - публичный ответ в комментарии — включить, 3 варианта (ниже), чтобы не выглядело как бот;
   - сообщение в директ — текст и кнопка ниже;
   - опционально «Ask to follow before sending link» — выключить: лишний шаг режет переходы.
5. Проверить с личного аккаунта: написать «жаба» под П8 → должен прийти ответ в комментарии и директ.

## Тексты
**Ответ в комментарии (случайный из трёх):** «Жаба уже в директе 🐸» · «Отправил в личку» · «Лови ссылку в директе»

**Директ:**
> Привет! Это Кубыш — жаба, которая не душит 🐸
> Начни с «Получки»: за минуту увидишь, сколько у тебя свободно до зарплаты и хватит ли до неё.
> Бесплатно в App Store 👇

Кнопка «Открыть в App Store» → `https://apps.apple.com/ru/app/id6778792103?ct=ig_dm&mt=8`

## Как мерить
Каждое воскресенье: число комментариев «жаба» по рилсам (ManyChat → Contacts) и установки с `ig_dm` в ASC → App Analytics
→ Источники → Ссылки на кампании. Это же база для сравнения «ролики с персонажами против роликов только с маскотом».

⚠️ **Метка без `pt` может не считаться.** App Analytics засчитывает кампанию по паре `pt` (код провайдера) + `ct`. В наших ссылках
`pt` нет ни в одной. Кирилл: ASC → App Analytics → «Кампании» → «Создать ссылку» → скопировать `pt=…` и прислать Клоду — допишу во все ссылки.
