# Выгрузка прода

Одна команда со своего Mac, из корня репозитория маркетоса:

```bash
bash Docs/tools/prod/export.sh
```

Скрипт сам находит сервер (DNS `api.kubysh.com`), подключается по SSH, находит контейнер Postgres, проверяет
свежесть витрины и кладет в `~/kubysh_prod_export/<дата_время>/` и архив `.zip`:

| Файл | Что внутри |
|---|---|
| `01–21_*.csv` | таблицы: люди, активные дни (витрина и сырые события), события по людям и дням, установки, онбординг, периоды Получки, монетизация, платежи, подписки, страница оплаты, приглашения, банки, App Store |
| `verify_dashboard.txt` | сверка дашборда PMF: люди, DAU/WAU/MAU, когорты G1/G2, платящие, пейвол, загрузки — витрина против сырых событий рядом |
| `gtm_snapshot.txt` | срез для GTM: каналы, страны, оплата по шагам, сегменты «подушка / цели», ядро 4+ недели |
| `_log.txt` | журнал запуска и ошибки |

Безопасность: каждое подключение только на чтение (`default_transaction_read_only=on`, запись в базу невозможна).
Почт, телефонов, имен, номеров заказов и сырых уведомлений банка нет; id людей заменены на md5-префикс.
Архив не класть в этот репозиторий: он публичный.

Переменные, если нужно: `HOST=root@IP` (другой сервер), `OUT=папка` (куда класть).
Сервер `207.154.252.247` скрипт отвергает: там замороженная база от 27.08.2026.
Схема сверена с `finik-backend` `app/infrastructure/persistence/models.py` на 04.11.2026; при смене моделей
поправить SQL в `export/`.
