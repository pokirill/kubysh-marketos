# Карточки App Store — генератор

Собирает карточки 1290×2796 (6.9") в светлом стиле 1.6.3: мятный градиент, заголовок Montserrat Bold
(кегль сам уменьшается под длинную строку), подпись с ключевыми словами жирным зеленым, телефон в тонкой
рамке с тенью, уходит за нижний край. Верх телефона выровнен на всех карточках (панорама не «скачет»).

## Как собрать
```bash
cd "/Users/kirillpopov/Documents/Kubysh - growth/Docs/tools/store_cards"
python3 card.py --config cards_1.6.3.json
```
Для новой версии: скопировать `cards_1.6.3.json` в `cards_X.Y.Z.json`, поменять `out_dir`, `shots_dir`, кадры и тексты.

## Поля карточки
- `headline` — 2 строки заголовка, 2–4 слова.
- `segments` — подпись: `[текст, 1]` выделено жирным зеленым, `[текст, 0]` обычный. Запятую держать внутри
  своего сегмента («Бюджет на день,»), иначе появится пробел перед запятой. Выделять 2–3 мысли, не все.
- `shot` — имя файла в `shots_dir` или абсолютный путь.
- `clean: true` — заменить строку состояния на 9:41 с полной батареей (для снимков с телефона).
  Снимки из симулятора с 9:41 не трогать.
- `arrow_out` / `arrow_in` — пунктирная стрелка в полях между соседними карточками панорамы.

## Правила кадров (из опыта ASO 1.6.1 и 1.6.3)
- Первые 3 кадра видны в поиске и решают конверсию: «Получка» → план за 2 минуты → траты скриншотом.
- Цели и накопления — 3 кадра: ценность «помогает накопить».
- Исходники снимать на iPhone 17 Pro Max сборки из стора, строка состояния 9:41. Для «Получки» лучше живые
  цифры с телефона, но без оранжевого календаря (обрезать или свернуть).
- Тексты: без «ё», без длинных тире, без цен, «бесплатно» только как «первый период бесплатно».
- Раскладка и тексты версии: `Docs/publications/ASO_V1.6.3_SCREENSHOTS.md`.

## Анимированные карточки релиза (02.10.2026)

`release_anim.py --config anim_release_1.7.json` — MP4 1080×1350 для альбома Телеграма и карусели Инстаграма;
`--reel <файл.mp4>` — те же сцены подряд в 1080×1920 с полосками прогресса; `--posters` — только PNG последних кадров;
`--only <name>` — одна карточка. ffmpeg не нужен: кадры идут в `mp4enc` (AVFoundation). Собрать его один раз:
`DEVELOPER_DIR=/Users/kirillpopov/Downloads/Xcode.app/Contents/Developer xcrun swiftc -O mp4enc.swift -o mp4enc`
(бинарник в `.gitignore`).

Виды карточек: `cover` (иконка, версии прокручиваются, плашки фич), `shot` (случай → телефон → крупный план →
ответ), `fixes` (пункты с галочкой и версией), `end` (иконка и призыв). Поля `shot`: `box` — область крупного плана
в пикселях скриншота; `anchor` — откуда она выезжает, если крупный план из другого кадра (`pop_shot`); `badge` —
счетчик под крупным планом (`from` → `to`).

Правила, оплаченные первой сборкой:
- Заголовок виден с первого кадра: первый кадр становится превью в Телеграме и обложкой видео в карусели.
- Все числа на карточках одного поста — из одного демо-дня. Две карточки с одинаковым «завтра можно» при разных
  сценариях читаются как ошибка (так и вышло: тестовый сид дал совпадение, пересняли).
- Подпись счетчика должна быть правдой и в первом кадре счета: «Завтра можно больше», а не «Завтра можно 4 064».
- В `ImageDraw` по RGBA полупрозрачная заливка не смешивается, а записывается: кодировщик игнорирует альфу, и
  «светлая» полоска выходит полностью зеленой. Для фона дорожек брать непрозрачный светлый цвет.
