# Задача Саши: ответы в комментариях с измеримым результатом

**Статус:** в работе с 22.09.2026. **Бриф:** `Docs/team/BRIEF_SASHA.md`.

## Зачем

В сети много людей, которые уже жалуются на нашу боль: «не могу накопить», «не хватает до зарплаты», «трекер бросил,
толку ноль». Им не нужна реклама, им нужен ответ по сути. Хороший ответ от живого человека из команды приводит
людей дешевле любого поста. Результат считаем по отдельной ссылке «11», журналу и еженедельному отчету.

## Кому отвечаем

Людям со стабильной зарплатой (аванс, премии) и iPhone, у которых есть боль из банка
`Docs/product/MARKETING_IDEAS_BANK.md` (разделы 1 и 2, рубрика «Жиза»). Не отвечаем фрилансерам с
нерегулярным доходом и тем, кто ищет приложение на Android.

## Где искать (каждый день, 20 минут)

- **Тредс, VC, Пикабу, Телеграм-чаты про деньги.** Поисковые фразы: «не могу накопить», «не хватает до зарплаты»,
  «посоветуйте приложение для бюджета», «бросил вести учет», «куда уходят деньги», «как дожить до зарплаты».
- **Наши площадки:** LinkedIn пост 2 (55 комментариев: «какую проблему решает», «трекер вайбкодера»,
  «монетизация»), Хабр статья 3 со вт 22.09, посты тем дня Кирилла.

## Как отвечаем

- Сначала по сути боли: полезный ответ, который работает даже без Кубыша.
- Затем честно: «я из команды Кубыша, мы как раз это решаем так-то».
- Ссылку даем только по просьбе. В профиле ссылка «11»: https://apps.apple.com/ru/app/id6778792103?ppid=465a3bee-2614-4ccc-b708-7c33bc3ca334
- Не больше 10 ответов в день, без копипасты: заготовки подстраиваем под человека.
- **Нельзя:** спорить, ругать конкурентов по названию, обещать функции, которых нет
  (`Docs/product/CONTENT_TOPICS_BANK.md`, раздел В), писать «бесплатно» и цены.

### Формат пятничного отчета

```
Неделя: ДД.ММ–ДД.ММ
Ответов: N (цель 40+)
Людей ответили: N (цель 10+)
Попросили ссылку: N (цель 5+)
Лучшая площадка: … (N ответивших)
Лучшая тема: Т… (N ответивших)
Страница «11»: просмотры N, загрузки N (цифры дает Кирилл из App Store Connect)
Что попробую иначе на следующей неделе: …
```
