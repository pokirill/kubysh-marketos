# Илья: темы Кирилла в 2D-сюжетах, неделя 09–15.11 (постановка для агента)

**Почему.** На 08.11 ролики Кирилла (жабы и инфографика) в Инсте собирают до 500 просмотров. У Ильи в аккаунте
kubyshich 7 из 28 роликов собрали 2 500–3 900, остальные 26–620. Формат Ильи работает лучше, поэтому боли и
сюжеты, которые Кирилл уже разобрал, переносим в 2D-сюжеты Ильи. **Лидеров (7 роликов 2,5–3,9 тыс) Илья знает сам:
их хуки, героев и длину повторять в первую очередь.**

**Читать перед работой:** `Docs/team/ILYA_AGENT_CONTEXT.md` (формат, язык, герои), затем этот файл. Примеры
раскрытия болей по секундам: `Docs/publications/82_Scripts_Kirill_03-08.11.md`, `85_Reels_spending_entry_scripts.md`.

## Правила (коротко)

- Одна боль, один жизненный сюжет, 15–25 с, хук в первые 1,5 с: смешной итог, ценник крупно или узнаваемая фраза.
- Герой узнаваем: Батракан, Батрачка, Петрович, Душная = сам зритель (ноет, откладывает, боится). Кубыш = сын маминой
  подруги: у него все получается, отвечает одной цифрой, не учит и не командует.
- Приложение только в конце на 2 с. Слова «план», «сумма на день», «комфортно» не в первых секундах.
- «Оптимально», а не «можно тратить». Без «экономь», «урежь». Подписи без «ё» и длинных тире, голос = подпись.
- Банки: Т-Банк, Сбер, Яндекс, только текстом, без логотипов. Вход в банк из приложения, траты подтягиваются сами,
  пароль Кубыш не видит, списать ничего не может. Есть напоминание о платеже на конкретную дату.
- Сценарий на ок Кириллу до рендера. Ссылка в описании Shorts с меткой `ct=yt_i<номер>`.
