# Команда: как работаем

Все работают в этом репозитории (`git@github.com:pokirill/kubysh-marketos.git`): единый контекст и трекинг.
Задача сделана, только когда результат лежит здесь. Код продукта живет в iOS-репозитории, но журнал и отчеты
по задаче ведутся здесь.

## Перед первой задачей (30 минут)

1. `MANIFEST.md` — во что верим и как пишем.
2. `Docs/product/VALUE_MAP.md` — для кого Кубыш, главное обещание, 6 тем.
3. `Docs/product/MARKETING_IDEAS_BANK.md` — все идеи, хуки, фичи по джобам. Новую идею пишешь сюда, раздел 6.
4. Свой бриф ниже и план недели `Docs/PLAN_WEEK_2026-09-21.md`.

## Как сдавать

- Результат (тексты, таблицы, отчеты) — в папку, указанную в брифе; файлы, а не ссылки на чаты.
- Коммит: `git add <конкретные файлы>` (не `git add -A`), сообщение «<имя>: что сделано».
- В брифе отметить `[x]` у задачи тем же коммитом.
- Застрял больше дня — строка в разделе «Вопросы» своего брифа и сообщение Кириллу.
- Не взял задачу за 2 дня — Кирилл решает: сделать самому, отложить или вычеркнуть.
