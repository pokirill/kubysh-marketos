# Партнерская программа: авторы для захода (05.11.2026)

Канал №1 GTM (`strategy/GTM_2026-11.md`, раздел 6). Модель: платим за платящего, 250 ₽ за месячный тариф и 350 ₽
за годовой (ориентир Кирилла 05.11, пересчитать после первых данных). Крупным авторам — гибрид «небольшой фикс + за
платящего» только после точки 20.12.

- **Правило 1 `AGENTS.md`:** перед сообщением каждому — открыть канал самому, снять просмотры последних 10 роликов,
  найти конкретный ролик с датой для крючка.
- **Добрать до 60:** раздел «Как добрать» ниже — 1–2 часа ручной работы по фильтрам, или открыть сессии доступ к

## Перед любым контактом (обязательно)

1. **Реестр иноагентов Минюста.** С 2024 года размещать рекламу у иноагентов запрещено. Проверять каждого.
2. **Маркировка.** Ролик с личной ссылкой и вознаграждением — реклама, нужен erid через оператора рекламных данных,
   при любой модели оплаты, включая оплату за платящего.
3. **Механика.** Привязка платящего к партнеру (PARTNER-PAY-1) делается на неделе 09.11. До проверки на тестовом
   партнере **не обещать выплаты**, только собирать интерес (правило «не обещать механик, которых нет»).
4. **Репутация.** Не брать инфобизнес с менторством и обещаниями дохода, трейдинг, крипту, кредиты.

## Сообщение (после PARTNER-PAY-1; до этого — только «интересно ли»)

Структура `skills/OUTREACH.md`: крючок из конкретного ролика с датой → кто я в одной строке → что предлагаю →
почему это зайдет их зрителям → низкий порог ответа.

```
[Имя], смотрел ваш ролик «[название]» от [дата], особенно [конкретный момент].

Я Кирилл, делаю Кубыш: приложение для iPhone, которое раскладывает зарплату и показывает, когда соберется подушка и цель. Без таблиц и без урезания привычных трат.

Хочу предложить партнерство без риска для вас: персональная ссылка, и за каждого, кто оформит подписку, мы платим [250 ₽ за месячную / 350 ₽ за годовую]. Отчет раз в неделю. Маркировку беру на себя.

Вашим зрителям это в тему: [почему — связь с их роликом про деньги / поездку].

Если интересно, пришлю ссылку и покажу приложение за 10 минут.
```
