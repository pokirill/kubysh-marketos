## Как вообще с ними связаться

В продукте **уже есть механизм личного обращения к пользователю**, и им почти не
пользовались: за всё время создано 2 обращения, доставлено 1, ответ получен 1.

- Эндпоинт: `POST /admin/custdev/outreach`, форма админки — `/admin/custdev`
- Поля: `nickname` (обязательно), `message` (1-1500 символов), `topic`
- Допустимые темы: `custdev_invite`, `online_talk`, `product_question`
- Сообщение кладётся в очередь пользователю и дополнительно шлётся пуш через APNs
- Статусы видно там же: создано, доставлено, просмотрено, отвечено

🚨 **Ограничение: обращение адресуется по НИКУ.** Человек без ника недостижим вообще.

## Как отправить

Подставьте свой ник вместо `@NICK`, дальше из папки бэк-репозитория:

```
set -a && . ./.kubyshka-admin.env && set +a
curl -s -u "$ADMIN_USERNAME:$ADMIN_PASSWORD" -A "curl/8.4.0" \
  -X POST https://api.kubysh.com/admin/custdev/outreach \
  --data-urlencode "nickname=vvalltor" \
  --data-urlencode "topic=online_talk" \
  --data-urlencode "message=ТЕКСТ"
```

Проще и безопаснее — через форму в `/admin/custdev`, там же видно статусы доставки.

## Что решить до отправки

1. **Подписка навсегда** в обоих текстах — это обещание живому человеку, снимите, если не
   готовы его держать.
2. **Ваш ник в телеграме** — я его не знаю, стоит заглушка `@NICK`.
3. **Лимит 1500 символов** оба текста проходят с запасом.
4. **alex50 не заходил с 20 августа.** Пуш может не дойти или прийти без реакции. Это
   нормально: цена попытки ноль.
