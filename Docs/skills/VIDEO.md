# Скилл: VIDEO — рилсы и ролики Кубыша (конвейер, инструменты, планка качества)

Гипотеза влияния: рилсы — главный канал охвата и установок (ct-метки, комментарий «план» → ссылка в директ).
Правила и планка — `publications/66_Content_plan_from_19.10.md` (раздел 0, «Правила рилса v5»), уроки —
`publications/53_Reels_scripts_v2.md` («Уроки серии»), передача дел — `publications/68_Video_HANDOFF_2026-10-19.md`.

## Конвейер
1. Сценарий и раскадровка — в чат Кириллу (время, кадр, прием камеры, голос = подпись). Производство только после «ок».
   Сначала 1–2 образца, пачка — после «ок».
2. Генерация Higgsfield — только согласованное и переиспользуемое. Голоса — **одним дублем** на пачку роликов
   (`generate_audio`, `text2speech_v2`, `elevenlabs`, Holden `3c9d6053-6334-592c-8997-4e325286af3f`, разрывы `<break time="1.5s" />`),
   клипы Kling 3.0 по 10 кредитов за 5 с со стартовым кадром из истории (новых картинок не генерировать без нужды).
3. Голос: числа словами и **округлены до сотен с «примерно»** (подпись — то же число с «≈»); нарезка дубля по словам
   (`tools/reels/vocheck.py`), ускорение ×1,2 без смены высоты (`tools/reels/tstretch`, `*_f_48k.wav`).
4. Сборка — `tools/reels/studio.py` + `episodes/<имя>.py`. Серии Б/Т/С — шаблон `episodes/scr.py`
   (голос из файлов, `problem_fn`/`insert`/`result_fn`, клипы Кубыша `kub_intro`/`kub_cta`), метафоры кодом —
   `episodes/meta.py` (табло, эксель со следствием, ячейки, секундомер, конверты), библиотека 3D-Кубыша — `episodes/lib.py`.
   Хук — холодное открытие итогом со своим голосом (`hook_clip`), обрезать до начала финальной реплики.
   Вступление с 21.10 — под сюжет: «Я Кубыш, приложение на айфон. <польза под этот ролик>». Плашку «приложение для
   iPhone» не ставить (Кирилл: шум без ценности), призыв «напиши „план“» не ставить (в комментариях никто не пишет);
   финал A «Скачай бесплатно» / B «Посчитай план за 3 минуты» — один ролик в двух версиях на разные дни.
   Сюжетные ролики с героями — `episodes/story.py` (реплики подряд, у каждой свои кадры, `hook=True` — холодное открытие).
   Диалог в кадре — только липсинк по готовому аудио (`wan2_7`, `start_image` + `audio_references`, аудио без ускорения),
   иначе рты не совпадают. Голоса: Кубыш Holden, Ксюша Xenia, подруга Vera; новые голоса показывать Кириллу пробами.
4а. Перед производством сценарий читает оценщик без контекста («рандомный рилс в ленте»): на какой секунде листает,
   понял ли боль и ценность. Боль — словами зрителя, решение объясняет «почему так лучше», обещание видно на экране.
5. Лист кадров каждые 0,5 с (`--preview`) до финального рендера; `vocheck.py` на каждой новой реплике.
6. После «ок»: файл и обложка в папку дня (`Рилс ЧЧ-ММ <название>.mp4`), раздел в `Тексты.md`
   (Инста, Shorts с `ct=yt_<id>`, ТГ), запись в `AI_CHANGELOG.md`, коммит.

## Внутренние инструменты (`tools/reels/`)
`studio.py` (движок), `vframes` (кадры из mp4), `mux`/`mp4enc` (сборка без ffmpeg), `tstretch` (ускорение речи),
`vocheck.py` (mlx-whisper: текст и тайминги слов), кадры записи экрана по точному времени — `AVAssetImageGenerator`
(запись симулятора идет с переменной частотой). Записи экрана — «Рилсы маскот/Записи_экрана_150/», профиль Ксюши —
симулятор QA-Claude-17.

## Промо-ролик «Копить без тревоги» (`tools/reels/promo_hero.py`, 22.10)
Эталон для Reels/Shorts и рекламы. Жанр конкурентного референса — кинетическая типографика, но с сюжетом по джобам:
кинокадр тревоги (Higgsfield: картинка `gpt_image_2_5` с референсом героя → Kling 3.0) → пуши трат → поворот (Кубыш
щелкает) → пришла зарплата → конверты (обязательное, подушка и цель с датой) → остаток ÷ дни = «оптимально в день» →
пересчет после трат: «завтра», темп, «хватит до 25-го» → кинокадр облегчения → телефон с настоящей «Получкой» и CTA.
- Тёмная тема (как в приложении), шрифт SF Pro (`/System/Library/Fonts/SFNS.ttf`, вариации по имени), акцент зеленый.
- Темп ×1,3 (`TS`): на 21 с зритель не успевал погрузиться в проблему; ≈28 с.
- Версии: `HOOK=A|B|C INC=150|180|230 python3 promo_hero.py`; цифры пересчитываются, остаток делится на 15 дней без остатка.
- Музыка — Higgsfield `sonilo_music` (тревога → дроп), функция `music()` ставит дроп на щелчок и тянет середину до длины.
- Скриншот финала — реальная «Получка» с позитивным темпом (оранжевое «быстрее плана» спорит с посылом).
- Для карточки App Store кинокадры не годятся: превью должно быть из записи экрана приложения (отдельная версия 886×1920).

## Без Higgsfield: HTML-ролик (`tools/reels/html_mihalych/`, 28.10)
Когда Higgsfield нельзя или нет кредитов: анимация пишется как HTML со своей функцией `render(t)`, Playwright снимает
кадры (30 fps, 1080×1920), звук синтезируется `synth.py`, склейка ffmpeg. Работает в облачной сессии без Мака.
Ассеты: экраны и иконка — с лендинга `pokirill/site/landing/img/`. Голоса нет (TTS был через Higgsfield).

## Визуальная система (промо и экранные ролики)
- **Фон:** тёмный градиент (9,14,12)→(3,6,5) и два размытых пятна (зеленое сверху слева, синее снизу справа),
  медленно дрейфуют. Светлую тему не делать: в приложении ее нет.
- **Шрифт:** SF Pro (SFNS, вариации Bold, Semibold, Medium). Montserrat — только карточки стора старого стиля.
- **Размеры на кадре 1080×1920:**
  - заголовок 74 px Bold, межстрочный ×1,25, не длиннее 26 знаков в строке, иначе режется по краям;
  - главная цифра 200 px Bold;
  - подписи 44–46 px Semibold;
  - чипы (плашки-выводы «оптимально…», «темп…», «хватит до…») 50–52 px, ниже не читаются на телефоне;
  - карточки 940 px шириной, радиус 36–48, фон (22,29,27), обводка белым 9%, легкое свечение акцентом.
- **Цвета смысла:**
  - зеленый (62,207,134) — хорошо, итог;
  - красный (255,116,116) — траты и боль;
  - синий — обязательное;
  - янтарный — цели.
  - Акцент в заголовке — одно-два слова через `*слово*`.
- **Движение:**
  - вход 0,45 с с замедлением в конце (ease-out), строки заголовка с задержкой 0,08 с, уход 0,3 с вверх;
  - строки списка въезжают по одной с шагом 0,7 с;
  - цифра пересчитывается счетчиком 0,6–0,9 с, при «посадке» короткий пульс масштаба;
  - хук — резкий зум цифры 1,35→1;
  - финал — медленный наезд на телефон.
- **Темп:**
  - одна мысль на 2–3 с, текст держится не меньше 1,5 с после появления;
  - вся анимация ×1,3 от «быстрой» версии (Кирилл 22.10: иначе не улавливается).
  - Прогресс-бар сверху. Нет глифа ✓ — рисовать галочку кодом.

## Внешние инструменты (список Кирилла 20.10)
- **Используем:** `mlx-whisper` (установлен, модель whisper-small-mlx) — проверка «голос = подпись» и нарезка по словам.
- **Кандидаты, когда понадобится:** `librosa` (сетка долей под музыкальный трек), `opus-sound-layer` (CC0-звуки вместо
  синтеза), `claude-video` (агент смотрит готовый ролик целиком), `auto-editor` (длинные выпуски), OpenScreen
  (скринкасты с автозумом — сейчас наезды делает движок).
- **Не нужны сейчас:** FFmpeg (AVFoundation закрывает склейку и звук), HyperFrames/Puppeteer/GSAP/three.js (кадры рисует
  PIL), yt-dlp, ManimGX, Anatomy, pyannote/mlx-audio (один диктор).
