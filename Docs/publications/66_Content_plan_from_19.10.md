# Контент-план с 19.10.2026: «Подушка + отпуск. Финансы без духоты» (v3, финал на согласование)

v1–v2 — 19.10 утром. v3 — по замечаниям Кирилла 19.10 днем: учесть все прошлые правила рилсов (хук — итог видео, затем
«как пришли»), по 2 рилса каждый день, план не ограничивать датой, в сравнении с приложениями показывать красивый
интерфейс, продуманную аналитику и фокус на будущем, оживить маскота до уровня дорогого мультика, после основных роликов
сделать видео для первой карточки стора. Ответы Кирилла: «бесплатно» — эксперимент с и без; «Я пиарюсь» на Хабре
требует кармы — не идем; экранные записи и генерации Higgsfield делает Клод сам.

## 0. Правила рилса v5 (свод из `52_*`, `53_*` «Уроки», `54_*`, `59_*`, плана недели 12.10 и памяти по тону)

Каждый сценарий ниже проверен по этому списку.
1. **0–1,5 с — итог ролика:** финальная сцена или огромное число + открытая петля («как к этому пришли?»).
   **1,5–2 с — перемотка назад**, дальше история к итогу; итог возвращается в конце.
2. **Кубыш — автор:** крупно в кадре и говорит с первой секунды; к 3-й секунде прямо сказано, что он приложение
   («приложение, которое считает, хватит ли до зарплаты»). Вырезка в углу запрещена (фокус-группа 12.10: «невнятно»).
3. **Темп для СДВГ:** прогресс-бар сверху весь ролик, смена кадра каждые 1–1,5 с, удары звука, счетчики.
   Звуки тише голоса (`sfxgain 0.4`).
4. **Продукт живьем:** запись экрана (внесли → пересчиталось), в рамке телефона без растяжения, кадры по точному времени.
5. **Голос = подпись дословно**, одна строка, без точек в конце, без «ё» и длинных тире, текст вне зон кнопок Инсты.
6. **Тон:** Кубыш не командует и не разрешает («смотри», «давай посчитаем», «решаешь ты»). Поворот: думал → цифры →
   сам решил → облегчение. Финал — радость, экономия на себя.
7. **15–20 с, петля:** последний кадр наплывом в первый.
8. **Финал:** Кубыш представляется + иконка + призыв (эксперимент A/B ниже) + «Напиши „план“ — пришлю ссылку».
   Слоган: «Бюджет под твою жизнь, а не наоборот».
9. **Цифры только с экрана** приложения; доход в примерах 130–260 тыс.; суммы героев — из легенд `55_*`.
10. **Раскадровка до генераций, лист кадров каждые 0,5 с до рендера.**
11. **Higgsfield:** только клипы, без застывших картинок; Душная — одно состояние на серию; второстепенные люди явно
    отличаются от героя; реплика героя — на клип, где он говорит; у неоднозначных ударений — знак ударения.
12. Один ролик — одна ситуация и один сегмент, своя метка `ct`. Банки и ставки в кадре размываем (ст. 28 ФЗ «О рекламе»).

**Эксперимент «бесплатно».** Финал A: «Скачай бесплатно в App Store» (скачивание и базовые функции бесплатны). Финал B:
«Посчитай свою подушку за 3 минуты». Чередуем по роликам серий Б, Т, С (нечетные — A, четные — B), метки `ct=…_a` /
`ct=…_b`. Сравниваем просмотры, комментарии «план» и переходы после 10 роликов; в Директе с 27.10 — тот же ролик двумя
объявлениями, это чистый тест. Числа будут маленькие — решение по сумме, не по одному ролику.

## 2. Маскот как герой дорогого мультика

Сейчас Кубыш — 2D-кукла движка: картинка с прыжками и морганием. Предлагаю 3D-героя:
1. **Образ.** Лист персонажа: 3D-жаба в стиле полнометражного мультфильма, мятно-зеленая, с монетой, мягкий свет,
   выразительная мимика. Свой дизайн, не похожий на Пепе: это заодно снимает риск жалобы правообладателя в рекламе
   (`CONTENT.md`). Ок Кирилла на образ.
2. **Библиотека из 12–15 клипов по 5 с** на ровном зеленом фоне: говорит в камеру, ловит монету, кивает, смеется,
   показывает на телефон, удивляется, машет, прыгает в кадр, торжествует, задумался, «перематывает» лапой.
   Движок вырезает фон и ставит Кубыша крупно поверх экранов и клипов.
3. **До готовности библиотеки** (около 23.10) — текущий риг, но крупно и в движении: позы, прыжки, наезды камеры, рот
   по голосу (правило 12.10).
