## Правила Кирилла (накоплено в эпизоде 1)
- **Все в 2D**, плоский мультик с толстым контуром. Higgsfield для видео и картинок не использовать, только для голоса
  (разрешил 28.10). Персонаж и фоны рисуются кодом (SVG), без генераций.
- Голос не ускорять сверх утвержденного; длина ролика может превышать 30 с («пусть превышает»).
- Фразы Кирилла ставить дословно. Титры = голос дословно, без «ё» в титрах, числа как на экране («≈3 400 ₽»).
- Экраны приложения — только настоящие (лендинг `pokirill/site/landing/img/`, свежие экраны просить у Кирилла).
- Версия «с чаем» для рекламы больше не нужна (29.10). Делаем органическую версию.
- Отвечать быстро: Кирилл просит не тянуть. Готовое видео присылать сразу, отчет — коротко.

## Юридические риски (Кириллу говорить один раз, решение за ним)
- Курение, алкоголь, грубые слова («охренеть», «сраные») в ролике с призывом скачать: закон «О рекламе», ст. 5 ч. 5 п. 3
  и ч. 6. Для платной рекламы так нельзя, для своего аккаунта — риск жалобы.
- «Сраные банки» спорит с планом продажи банку и с синхронизацией банков в 1.7.6.
- Пепе-стиль старой иконки (`CONTENT.md`); новая 2D-лягушка — свой образ.

## Как собирается ролик
Исходники: `tools/reels/html_mihalych/`.
- `garage.html` — сцены, риг Михалыча (IK рук, моргание, дыхание, рот), гараж, лампочка, муха, переход через телефон,
  экран «Получки», финал. Функция `render(T)`: реальное время → сюжетное через `VO.warp`; фон и муха в реальном времени.
- `vo_build.py` — реплики → обработка голоса, растяжка сюжета под реплики, титры по таймингам слов, огибающие ртов.
- `synth3.py` — музыка и звуки по сюжету + приглушение под голосом. `rec2.js` — кадры Playwright → mp4 (ffmpeg).
- `run_vo.sh smoke <папка wav> <words.json> <клон site> <out.mp4>` — полная сборка с голосом.
- Без голоса: `build_garage.py` (+ `synth2.py`).

Порядок для нового эпизода: сценарий и раскадровка Кириллу → «ок» → правка `garage.html` (новые сцены/позы) →
лист кадров каждые 0,5–1 с на проверку → голоса пачкой (`generate_audio_batch`, при 429 досылать по 1–2) →
проверка «голос = текст» распознаванием (faster-whisper `medium` с `initial_prompt` из имен) → сборка → кадры
из готового mp4 → отправка.

## Ограничения среды (важно)
- Сеть облачной сессии Claude **не пускает** CDN Higgsfield (`d8j0ntlcm91z4.cloudfront.net`, `d2ol7oe51mr4n9.cloudfront.net`,
  `upload.higgsfield.ai`), Silero, Hugging Face, Яндекс. Поэтому сборка с голосом идет в песочнице Higgsfield
  (`sandbox_exec`): клонировать публичные `pokirill/kubysh-marketos` (ветка с работой) и `pokirill/site`,
  `export NODE_PATH=$(npm root -g)` для Playwright, тяжелый рендер `background:true, size:"xl"`, поллить короткими
  вызовами (лимит вызова 60 с). Перед командой взять `media_upload`, PUT готового mp4 в той же команде, потом
  `media_confirm`. Ссылку на результат давать Кириллу (в чат файл не прислать).
- Если Кирилл откроет эти домены в настройках окружения (Network access → Allowed domains) — собирать локально и
  присылать файлом.
- Баланс Higgsfield на 28.10 ~47 кредитов; реплика TTS ≈ 0,3 кредита. Видео-генерации не запускать.
