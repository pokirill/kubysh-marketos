## Специальные страницы под запросы (вместо теста названий)
Название и подзаголовок в A/B Apple не тестирует. Но специальным страницам можно назначить ключевые слова
(`appCustomProductPageLocalizations → searchKeywords`, проверено API 12.10): по этим запросам в поиске показывается своя
страница со своими кадрами и промотекстом. Делаем 4 (слова — только из ключевых слов приложения):
1. **«Копилка на мечту»** — копилка, мечту, накопить, цели: первым кадр «Когда накопишь», цели с датами.
2. **«Бюджет до зарплаты»** — бюджета, дневной, получки, аванс, зарплаты: первым кадр «Сколько тратить сегодня».
3. **«Подушка безопасности»** — подушка, безопасности: кадр подушки и «хватит на N месяцев».
4. **«Учет трат»** — учет, трат, расходов: кадр «Скриншот из банка → траты по категориям».
Ссылочные страницы для соцсетей (01–09) не трогаем.
